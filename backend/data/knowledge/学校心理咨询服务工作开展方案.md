# 关于进一步加强学校心理咨询服务工作的通知

各学院（部）、各部门：

为深入贯彻落实教育部《高等学校学生心理健康教育指导纲要》（教党〔2018〕41号）精神，进一步完善学校心理健康教育与咨询服务体系，提升心理育人工作质量，现将学校心理咨询服务工作有关事项通知如下：

### 一、指导思想

深入学习贯彻习近平新时代中国特色社会主义思想，全面贯彻党的教育方针，落实立德树人根本任务，加强人文关怀和心理疏导，培育学生自尊自信、理性平和、积极向上的健康心态，促进学生心理健康素质与思想道德素质、科学文化素质协调发展。

### 二、工作目标

完善课堂教学、咨询辅导、危机预防、实践活动、队伍建设“五位一体”的工作格局，建立健全心理健康辅导与咨询的值班、预约、转介、重点反馈等制度，通过个体咨询、团体辅导、电话咨询、网络咨询等多种形式，向学生提供及时、连续、有效的心理健康指导与咨询服务。

### 三、组织架构

**（一）领导机构**

成立学生心理健康教育工作领导小组，由学校分管领导担任组长，成员包括学生工作部（处）、教务处、研究生院、保卫处、校医院等相关部门负责人。领导小组每学期召开心理工作专项研讨会，指导各部门和学院开展心理健康教育、辅导和援助工作。

**（二）工作机构**

学校设立心理健康教育与咨询中心（以下简称“心理中心”），挂靠学生工作部（处），为具体负责实施大学生心理健康教育和咨询工作的专职机构。

**（三）工作网络**

完善“学校—院系—班级—宿舍”四级心理育人工作网络。各学院设立心理辅导站，各班设立心理委员，各宿舍设立心理信息员。

### 四、服务内容与形式

**（一）个体心理咨询**

面向全校学生提供一对一心理咨询服务，涵盖学业压力、情绪困扰、人际关系、自我成长、职业规划等主题。每次咨询时长50分钟，原则上每学期每生不超过8次。

**（二）团体心理辅导**

定期开展主题性团体辅导活动，如同质性成长小组、人际关系训练营、压力管理团体等。

**（三）心理危机干预**

建立“学校—院系—班级—宿舍”四级预警网络，每年面向全体新生开展心理普测，对重点关注学生群体进行分级干预。健全心理危机转介诊疗机制，强化家校、校医协同联动。

**（四）心理健康教育活动**

结合“5·25大学生心理健康日”“10·10世界精神卫生日”等节点，以及开学季、考试季、毕业季等重要时间节点，开展心理健康教育实践活动。

### 五、服务保障

**（一）咨询师队伍建设**

心理中心配备专兼职心理咨询师，所有咨询师均须具备国家心理咨询师资格证书或心理学相关专业背景。定期开展业务培训、案例分析和督导，保证心理咨询服务在专业化、规范化框架下进行。

**（二）经费保障**

心理咨询服务面向本校全日制在校学生**免费**开放。

**（三）制度建设**

建立健全心理咨询预约制度、值班制度、转介制度、档案管理制度及保密制度。参照专业伦理和行业规范建立心理咨询管理机制，保障学生权益，规范学生心理档案的管理。

### 六、工作要求

1. 各学院应高度重视学生心理健康工作，积极配合心理中心开展宣传教育、危机排查与干预转介等工作。
2. 心理中心应不断提升咨询服务的专业化水平，定期开展个案研讨与督导。
3. 全体咨询师应严格遵守《中国心理学会临床与咨询心理学工作伦理守则》，尊重学生隐私，恪守保密原则及保密例外规定。
4. 学生应树立主动求助意识，珍惜心理咨询资源，按时赴约，如需取消请提前告知。
